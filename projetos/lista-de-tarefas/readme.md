# Lista de Tarefas

Aplicação simples de lista de tarefas desenvolvida com HTML, CSS e JavaScript puro.

## Preview

![Preview da lista de tarefas](./Video%20Project%207.gif)

## Funcionalidades

- Adicionar novas tarefas pelo formulário.
- Impedir o cadastro de tarefas vazias.
- Marcar uma tarefa como concluída clicando sobre seu texto.
- Desmarcar uma tarefa concluída clicando novamente sobre seu texto.
- Excluir tarefas pelo botão **Deletar**.
- Layout responsivo para telas menores.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Abra o arquivo `index.html` em um navegador.
2. Digite uma tarefa no campo de texto.
3. Clique em **Adicionar**.

Também é possível abrir a pasta no Visual Studio Code e usar uma extensão como o Live Server para iniciar a página localmente.

## Observação

As tarefas não são armazenadas no navegador. Ao atualizar ou fechar a página, a lista é reiniciada.
